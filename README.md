## 📖 About the Project

**PS5-on-PC** is a high-performance, open-source PlayStation 5 emulator built for the PC.
It replicates the PS5's custom hardware — the Zen-based CPU, the RDNA 2.0 GPU and the
unified memory architecture — so that PS5 titles run natively fast on your computer. 🖥✨

No console. No subscription. No extra fees. **Just your PC, the emulator, and your games.** 🕹

> 💡 Drop in your PS5 game file, press **Start**, and enjoy 4K60 gaming on your own machine!

## 📥 Installation

### 🐧 Linux (recommended)
```bash
git clone https://github.com/yourname/ps5-on-pc.git
cd ps5-on-pc
./install.sh
./ps5emu --load "GTA6.ps5"
```

### 🪟 Windows
```powershell
git clone https://github.com/yourname/ps5-on-pc.git
cd ps5-on-pc
.\install.ps1
.\ps5emu.exe --load "GTA6.ps5"
```

### 🍎 macOS
```bash
brew install yourname/tap/ps5emu
ps5emu --load "GTA6.ps5"
```

> ✅ That's all — one command and you're gaming. 🍻
